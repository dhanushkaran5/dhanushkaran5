### Activate or repair the contribution snake

For the animation to display, GitHub Actions must generate the SVGs and publish them to the `output` branch.

1. Open your profile repository: [dhanushkaran5/dhanushkaran5](https://github.com/dhanushkaran5/dhanushkaran5).
2. Create `.github/workflows/snake.yml` on your default branch.
3. Add the workflow below and commit it.
4. Open **Actions** and run **Generate contribution snake** with **Run workflow**.
5. Once the run succeeds, check the `output` branch for both SVG files.

Create `.github/workflows/snake.yml`:

```yaml
name: Generate contribution snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      - name: Generate contribution snake SVGs
        uses: Platane/snk@v3
        with:
          github_user_name: dhanushkaran5
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Publish SVGs to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**Troubleshooting**
- If your default branch is `master`, change `push.branches` from `main` to `master`.
- In repository **Settings → Actions → General → Workflow permissions**, allow workflows to have read and write permissions if the workflow is blocked from publishing.
- Check the Actions run log for errors. The snake image links won't work until the workflow successfully publishes the files to `output`.
- You don't need to create the `output` branch manually; the publishing action creates or updates it.
